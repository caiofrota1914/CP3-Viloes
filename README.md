# 🧠 A Mente dos Vilões

Projeto Web acadêmico desenvolvido em equipe durante a graduação de **Engenharia de Software na FIAP**.

A proposta é explorar a história, as motivações e as características de grandes vilões da cultura pop por meio de páginas individuais e uma interface central de navegação.

## 🎭 Vilões apresentados

- Coringa
- Thanos
- Madara Uchiha
- Chef Skinner
- Duende Verde

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript
- Git e GitHub

## 🤝 Desenvolvimento colaborativo

O projeto foi desenvolvido com versionamento de código e colaboração pelo GitHub, utilizando **branches, commits e Pull Requests** para integrar as contribuições da equipe.

### Contribuição de Caio Frota

- Estruturação e estilização da página com HTML e CSS
- Ajustes e integração com a página inicial
- Resolução de conflitos durante a integração
- Abertura e merge de Pull Request para incorporar as alterações à `main`
